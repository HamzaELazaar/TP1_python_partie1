# TP1 Python — Partie 1

Notebook d'exercices Python portant sur les notions de base : conversions de types, conditions, boucles, fonctions et structures de données.

## Contenu

Le notebook `TP1python_partie1.ipynb` contient des rappels de cours et des exercices corrigés sur :

- les conversions entre chaînes de caractères, entiers et nombres décimaux ;
- le calcul d'une moyenne pondérée ;
- les conditions et l'analyse d'une équation du second degré ;
- les boucles `for` et `while`, avec validation d'une saisie ;
- les fonctions, les paramètres par défaut, `map()` et `zip()` ;
- les listes et le calcul de la médiane ;
- les dictionnaires, listes et tuples dans une configuration multi-agents.

## Ouvrir le notebook

Le notebook peut être consulté sur GitHub ou ouvert dans Jupyter Notebook / JupyterLab. Pour l'exécuter localement, installez Python et Jupyter, puis lancez depuis ce dossier :

```bash
python -m pip install notebook
jupyter notebook TP1python_partie1.ipynb
```

Certaines cellules demandent des valeurs au clavier avec `input()`. Exécutez-les individuellement et saisissez les valeurs demandées dans la console du notebook.
